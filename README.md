Research homepage
=================

Plain static HTML, no build step. Structure follows
[pengsongyou.github.io](https://github.com/pengsongyou/pengsongyou.github.io);
the Miscellanea section follows [jonbarron.info](https://github.com/jonbarron/jonbarron_website).

```
index.html           the whole homepage (content + CSS)
media/               photo, logos, paper/talk teasers
files/               CV and other PDFs
script/functions.js  news "show more", Selected/Full List toggle, hover teasers
.nojekyll            tells GitHub Pages to serve files as-is
```

Preview: open `index.html` in a browser.
